# Titanic — источник данных

- Набор: [OpenML Titanic, ID 40945, version 1](https://www.openml.org/d/40945).
- Авторы: Frank E. Harrell Jr., Thomas Cason; источник — Vanderbilt Biostatistics, исторические данные Encyclopedia Titanica.
- [Метаданные OpenML](https://www.openml.org/api/v1/json/data/40945): licence = `Public`. Это обозначение OpenML; отдельная лицензия исходному набору здесь не приписывается.
- [Исходный ARFF](https://openml.org/data/v1/download/16826755/Titanic.arff), получен 7 октября 2026; MD5 проверен по метаданным: `60ac7205eee0ba5045c90b3bba95b1c4`.

`titanic.csv` содержит все 1 309 строк источника, в исходном порядке, только столбцы pclass, sex, age, sibsp, parch, fare, embarked, survived. Значение `?` заменено пустой ячейкой. Исходы не синтезировались и не исправлялись. Имена, билеты, каюты, пункт назначения, boat и body исключены. В частности, boat и body известны после катастрофы и раскрывают исход.

Сервер создаёт отдельное воспроизводимое разбиение клуба: 1 009 train, 300 test (200 открытых / 100 закрытых для рейтинга). Во всех частях сохраняется примерно исходное соотношение классов. ID назначаются после перемешивания и не совпадают с Kaggle PassengerId. Для всех участников одной установки набор один и тот же.

Это открытый исторический учебный датасет: исходные ответы доступны публично. Секрет сервера защищает разбиение рейтинга, но не делает исторические метки неизвестными. Не используйте один автоматический балл как доказательство честности или основание отбора; проверяйте ноутбук, воспроизводимость и объяснение участника. Загрузка готовых ответов и сопоставление с исходными метками запрещены правилами учебного задания.
